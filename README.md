A Monophonic Sequencer/Synthesiser in MAX/MSP 

Place selected Melodies and Sequences into the into the message box and press enter for the sequences to be periodically rotated on a variable time based schedule.

Additionally there is functionally for you to scramble your original sequence to produce a different permutation of information that is rotated and played.
